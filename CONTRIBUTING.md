# Contribuir a LinSweep

Las contribuciones a LinSweep son bienvenidas.

LinSweep se encuentra actualmente en desarrollo y está enfocado principalmente en Arch Linux.

## Entorno de desarrollo

Clona el repositorio:

```bash
git clone https://github.com/NDEXTHOR/linsweep
cd linsweep
```

Crea un entorno virtual:

```bash
python -m venv .venv
source .venv/bin/activate
```

Instala LinSweep en modo editable:

```bash
pip install -e .
```
